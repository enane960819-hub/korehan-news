# KoreHani 사이트 비판적 분석 + 개선안 (2026-10-26)

근거: 로그인 상태로 주요 8개 페이지를 휴대폰(390px)·PC(1366px)에서 직접 렌더링한 스크린샷,
전체 31개 사용자 페이지 크롤링, 그동안의 코드·DB 점검 결과.
우선순위: ① 학습 효과 ② 재방문(리텐션) ③ 수익화. **레이아웃 → 디자인 → 로직 → 기능** 순서.

---

## 1. 레이아웃 (가장 먼저)

### 핵심 진단
**"첫 화면에 할 일이 안 보이고, 화면 위에 떠 있는 것이 너무 많다."**
콘텐츠보다 배너·팝업·떠다니는 버튼이 먼저 보이고, 페이지마다 구조가 달라서 학습자가 "지금 뭘 하면 되는지"를 매번 다시 찾아야 함.

### 1-1. 홈 상단이 배너로 막혀 있음 (P0)
- 휴대폰 첫 화면: ① 환영 배너 ② Beginner's Guide 배너 ③ 히어로 기사. 첫 기사가 화면 3분의 1 아래에서 시작.
- 환영 배너는 **글자가 거의 안 보임**(밝은 그라데이션 위 흰 글씨) + **이메일 주소를 그대로 노출**("Welcome back, enane960819+khqa").
- PC: "Your First Journey" 체크리스트 패널이 히어로와 오른쪽 기사 목록을 덮음.
- 🎯 버튼이 오늘의 표현 카드 위에 겹침.
- **개선**: 상단은 **"Today" 카드 하나**로 통합 — (인사 + 스트릭) / (오늘 할 3가지: 기사 1 · 복습 N개 · 표현 1) / (진행 바). Beginner's Guide·First Journey는 이 카드 안의 체크리스트로 흡수, 떠 있는 패널 제거. 이메일 대신 닉네임.

### 1-2. 홈 섹션 순서가 학습 흐름과 반대 (P1)
- 현재: 히어로 → 오늘의 표현/진행(버튼 3개 중복) → News → Conversations → **Korean Basics(맨 아래)**.
- 초보자(가장 많은 신규 유입)의 입구인 Korean Basics가 맨 아래, 레벨 무관하게 같은 순서.
- 진행 카드의 "Study Room / Growth Lab" 버튼은 하단 내비·상단 메뉴와 중복. "Quick win: Try a Story" 문구는 삭제된 기능 안내(잔재).
- **개선**: 레벨별 홈.
  - Seed: Today → **Korean Basics 이어하기** → 쉬운 기사(Seed) → 회화.
  - Sprout 이상: Today → 내 레벨 기사 → 회화 → Korea Buzz.
  - 진행 카드는 "오늘의 복습 시작" 1개 버튼만.

### 1-3. 휴대폰에서 떠 있는 요소 과다 (P0)
- 기사 페이지에 동시에: 하단 내비 + 🎯 + SAVE/TALK/STUDY 3개 + Prev/Next 알약 + "+10 Nyang" 토스트 + 배지 팝업 → **본문을 가림**(스크린샷 확인).
- **개선**: 기사 화면은 **하단 액션바 1줄**(저장 · 듣기 · 공부하기 · 다음 기사)로 통합, 하단 내비는 기사 안에서 숨김. 보상 토스트·배지는 한 번에 하나, 본문 밖(상단)에 2초.

### 1-4. 상단 메뉴 과밀 (PC) (P1)
- 메뉴 9개(Home, News▾, Conversations▾, Korea Buzz, Study Room, Shop, Playground, Growth Lab, Courses) + 헤더에 날짜·검색·Neon 토글·레벨 선택·알림·프로필.
- **개선**: 1차 메뉴 5개 — **Read**(News · Korea Buzz · Conversations) / **Study** / **Progress** / **Play** / **Premium**. Shop·My Room은 프로필 메뉴로, Neon 토글은 설정으로, 날짜 삭제.

### 1-5. 스터디룸이 "대시보드"가 아니라 "목록" (P0)
- 들어갈 때마다 "Welcome to Study Room" 모달이 화면을 막음.
- PC: 3단 + 진입점 20개 이상(Word Book, Grammar at a Glance, Weekly Quest, Topic, Phrase Munch, Speaking, Dictation, Key Expressions, Grammar Path, Flashcards…).
- 휴대폰: FAST TRACK / KOREAN SLANG / PHONE CALL / PHOTO DESC. 큰 이미지 카드가 세로로 길게 → 무엇부터 할지 모름.
- **개선**: 상단 **"오늘의 학습 3단계"**(① 복습 ② 이번 주 토픽 ③ 표현/듣기 1개, 완료 체크) + 그 아래 **라이브러리**(카테고리 탭: Read · Grammar · Vocab · Speak · Play). 환영 모달은 첫 방문 1회만.

### 1-6. Growth Lab · My Page 정보 구조 (P1)
- Growth Lab 첫 블록이 3D 우주 홍보 → 정작 "이번 주 진척"은 아래. 숫자 카드 그리드가 고르지 않음(Time today만 한 줄 전체).
- My Page: My Room이 플랜·진척보다 위, XP/티어가 두 군데(Accumulated XP + Tier Progress) 중복.
- **개선**: Growth Lab = 이번 주 요약(목표 대비) → 약점(문법·단어) → 추천 다음 행동 → (우주는 단어장 안 보너스). My Page = 프로필·플랜 → 진척 → My Room·인벤토리.

### 1-7. 세부 레이아웃 버그
- 기사 바이라인 "K I"로 잘림(기자 이름 표시 안 됨).
- 홈 하단 푸터 위 큰 빈 공간, 휴대폰 푸터 뉴스레터 영역 좌측 여백 0.
- Courses(요금) 페이지 휴대폰 길이 8,876px — 비교표·FAQ·라이브 수업이 반복. 요금 카드 → 비교표 → FAQ 3개 블록으로 축소.
- 히어로 이미지 로드 실패 시 어두운 화면에 "KoreHani" 글자만 보임 → 대체 이미지/그라데이션 + 섹션 색.

## 2. 디자인

- **테마가 두 개로 갈라짐**: 뉴스·홈은 밝은 화이트, 스터디룸·Growth Lab·진행 카드는 짙은 네이비/네온. 페이지 이동 때마다 다른 사이트처럼 느껴짐 → 밝은 테마 기준으로 통일, 다크는 시스템 설정 연동 다크모드로만.
- **글꼴 4~5종 혼용**: Happy Monkey(장난스러운 손글씨체, UI 전반), Playfair(세리프 헤드라인), Noto Serif KR, DM Sans, Source Sans. Happy Monkey는 작은 라벨에서 가독성이 떨어지고 신뢰감을 낮춤 → **UI: Inter + Noto Sans KR(또는 Pretendard) 1종, 헤드라인 1종**.
- **아이콘 혼용**: 이모지(🎯🔥📚💾)와 Lucide 아이콘이 섞임 → Lucide로 통일, 이모지는 보상 연출에만.
- **카드 스타일 제각각**: 사진 오버레이 카드 / 흰 카드 / 네온 카드 / 대문자 이미지 배너(FAST TRACK 등). 카드 컴포넌트 2종(콘텐츠 카드, 액션 카드)으로 정리.
- **대비·가독성**: 환영 배너, 회색 보조 텍스트(#94a3b8 on white), 네온 위 반투명 글씨 → WCAG AA(4.5:1) 기준으로 색 토큰 재정의.
- **언어 혼합**: 히어로에서 영어 제목 아래 한국어 요약 → 레벨에 따라 (Seed/Sprout: 영어 요약, Tree+: 한국어 요약 + 번역 토글).

## 3. 로직

- **숫자가 서로 안 맞음**: Growth Lab "Words today 20 / Read today 3" vs 같은 화면 "This week Articles 0, Words 0". XP도 30(오늘)·80(누적)·배지별 값이 출처마다 다름 → 통계 단일 출처(RPC 1개)로.
- **냥·XP를 브라우저가 직접 수정** 10곳(이미 보고) → 서버 RPC + 컬럼 UPDATE 권한 회수. 결제 켜기 전 필수.
- **AI 의존 기능이 크레딧 소진 시 깨짐**: 문법 레슨 356/358개, 기사 문장 분석(미캐시 기사), 회화 제목 번역 등. → 생성은 서버에서 미리(배치), 화면은 DB만 읽기. 실패 시 항상 대체 화면.
- **중복 시스템**: 단어 저장 경로 8개+, 복습(SRS) 구현 6개+, 문법 진입점 4개, 어순 드릴 6개 → 단어장 1 + 복습 큐 1 + 문법 경로 1.
- **모달·팝업 표시 규칙 없음**: 환영 모달·First Journey·배지·보상 토스트가 동시에 뜸 → "한 화면 한 알림" 큐.
- **레벨 반영 부족**: 레벨을 받아도 홈·스터디룸 구성은 동일 → 레벨이 콘텐츠 선택·UI 언어 비율·추천을 결정하도록.

## 4. 기능 (학습 효과 → 리텐션 → 수익화 순)

### 학습 효과
1. **하루 복습 큐 1개**(SRS): 저장 단어 + 틀린 문법 + 오늘 기사 표현을 하나의 "Review N" 큐로. 홈·스터디룸 첫 버튼.
2. **모든 문장 듣기(TTS) + 따라 말하기**: 기사·회화 문장 단위 재생, 발음 점수는 선택.
3. **레벨 맞춤 읽기**: Seed는 쉬운 버전 + 영어 번역 기본 표시, Tree+는 번역 접기. 문장 탭 분석은 유지.
4. **Korean Basics → 첫 기사 연결**: 기초 코스 완료 시 Seed 기사·회화로 자동 안내.
5. **문법 레슨 사전 생성**(크레딧 충전 후 1회) + 뜻별 레슨 분리((으)로 수단/방향 등).

### 리텐션
1. **주간 목표 + 스트릭 보호**(Streak Freeze 이미 있음) + 푸시/이메일 리마인더(하루 1회, 미학습 시).
2. **"오늘 할 3가지" 완료 연출**(작은 보상 1회) — 지금처럼 보상이 여기저기 흩어지지 않게.
3. **주간 리포트 메일**(이미 Growth Lab에 "inbox" 문구 있음) 실제 발송.

### 수익화
1. **Premium = 학습 시스템**: Article/Conversation Study, 복습 큐 무제한, 듣기·말하기 점수, 튜터 첨삭, 라이브 수업. 무료 = 읽기 + 하루 복습 20개.
2. **결제 전 정리 필수**: 냥 서버화, 현금 아이템 재오픈 여부 결정, 7일 체험 흐름 점검.
3. **연간 플랜 강조**($69/년)와 체험 종료 2일 전 알림.

### 덜어낼 것 / 보류 (결정 필요)
- 스터디룸 Help 탭(작문 패널 복제), Neon 테마, 기자 선물·호감도·포토카드·매니저 고용, 친구·방명록 — 학습 효과 대비 화면·코드 비용 큼.

## 5. 제안 진행 순서

1. **레이아웃 1차 (1~2일)**: 홈 상단 "Today" 카드 통합 + 배너/팝업 정리, 휴대폰 떠 있는 버튼 정리(기사 액션바), 환영 모달 1회, 바이라인·푸터 버그.
2. **레이아웃 2차**: 스터디룸 "오늘의 3단계 + 라이브러리", 상단 메뉴 5개, Growth Lab/My Page 순서.
3. **디자인 시스템**: 글꼴 2종, 색 토큰(대비 AA), 카드 2종, 아이콘 통일, 밝은 테마 통일.
4. **로직**: 통계 단일 RPC, 냥 서버화, 알림 큐, AI 사전 생성 파이프라인.
5. **기능**: 복습 큐 1개 → 문장 듣기 → 레벨 맞춤 홈 → 리마인더 → Premium 재정의.

> 사장님 지시 원칙: **화면을 바꾸는 작업은 시안(스크린샷)으로 먼저 확인받고 적용**.
