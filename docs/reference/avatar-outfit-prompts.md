# My Room character: new outfit prompts

Every outfit is drawn on the SAME character template as the current ones, once per hairstyle
(long, short, bob, curly), because each look is a full-body picture per hairstyle
(`<hair>-<outfit>.png` in `korehan/assets/avatar/`). One sheet = 3 outfits x 4 hairstyles = 12
figures. Send the sheets back with their letter; they are cut, background-removed and added to
Customize with a price or a study goal.

Hats or headwear drawn as PART of an outfit are fine (cowboy hat, chef hat); only hats placed
on top as separate accessories are banned (owner rule).

## 1. First message (attach `avatar-outfit-reference.png`)

```
I'm making outfit sprites for a cozy pixel-art character in my app. The attached picture shows the character template: the first four figures are the same girl with four hairstyles (long, short, bob, curly), the last two are finished outfits for reference.
Rules for EVERY picture: same soft pixel-art style, same face, same body size and proportions, same front-facing standing pose with arms down, same head size, full body from head to shoes, plain pure white background, no shadow, no text. Only the clothes change. Keep the hair exactly like the template unless the outfit covers it.
```

## 2. One message per sheet

If figures touch or are cut off, reply:
`Same sheet, but leave clear white space around every figure and keep each one fully inside its own cell.`
If one figure is wrong, redraw only that one: `Draw ONE figure, centred, nothing else: the <hairstyle> girl wearing <outfit>.`
