# Shop Items

Drop item images here, named by their slug (id with underscores → hyphens).
Recommended: landscape card ~640×360, centered subject, subtle background.

**Cash items on this app are cosmetic / ad-free / gifting only.** No XP
boosts, streak freezes, AI credits, or lesson unlocks — learning progress is
decided by effort, not wallet.
